# Engineering status

This directory is the current, auditable view of engineering work.

- `BASELINE.md` records the immutable starting evidence.
- `PROJECT_STATUS.md` is the dashboard.
- `WORK_ITEMS.md` is the detailed execution ledger.
- `DEPENDENCIES.md`, `BLOCKERS.md`, `RISKS.md`, `SECURITY_FINDINGS.md`, and `LOGIC_IMPROVEMENTS.md` contain domain-specific registers.
- `COMPLETED_WORK.md` records validated outcomes.

Statuses are `DISCOVERED`, `READY`, `IN_PROGRESS`, `BLOCKED`, `IMPLEMENTED`, `VALIDATED`, `DEFERRED`, or `REJECTED`. `IMPLEMENTED` is not completion; acceptance criteria must pass before an item becomes `VALIDATED`.
