# Multi-agent coordination

1. Record the baseline before delegation.
2. Give each review agent a disjoint read-only responsibility and the common finding contract.
3. Wait for every audit before structural changes.
4. Reconcile duplicates and conflicts centrally.
5. Serialize overlapping writes; parallelize only disjoint work.
6. Track accepted, deferred, rejected, and blocked findings.
7. Use an independent read-only reviewer after implementation.
