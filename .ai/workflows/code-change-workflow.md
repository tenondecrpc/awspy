# Code change workflow

1. Link the change to a requirement, defect, or work item.
2. Inspect current behavior and relevant Next.js documentation.
3. Add characterization or regression coverage.
4. Make the smallest compatible change.
5. Run focused tests, formatting, lint, and type checks.
6. Exercise page changes in a browser and run the full repository gate.
7. Update status, specs, risks, and rollback notes.
